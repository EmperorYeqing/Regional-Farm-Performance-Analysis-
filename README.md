# Regional Agricultural Performance Analysis

## Project Overview

This project analyzes agricultural performance across different regions to identify top-performing regions, measure land-use efficiency, evaluate crop profitability, and provide investment recommendations.

The analysis was conducted using Python, Pandas, NumPy, and Matplotlib.

## Business Objectives

The national agricultural board seeks to answer the following questions:

1. Which region performs best?
2. Which region uses land most efficiently?
3. Which crop generates the most revenue?
4. Which region deserves additional investment?
5. Which region requires intervention?

## KPIs Created

### Yield per Hectare

Yield_per_Ha = Yield_Kg / Farm_Size_Ha

### Revenue per Hectare

Revenue_per_Ha = Revenue / Farm_Size_Ha

## Key Findings

- South Region generated the highest total revenue.
- South Region achieved the highest land-use efficiency.
- East Region showed the lowest land-use efficiency.
- Rice was the most profitable crop.
- Soybean generated the lowest revenue.
- Farm size showed only a weak relationship with productivity.

## Recommendations

- Increase investment in South Region, particularly in Rice and Maize production.
- Study successful farming practices in South Region for possible adoption elsewhere.
- Investigate causes of low efficiency in East Region.
- Promote Rice and Maize cultivation due to their strong revenue performance.
- Conduct further studies to determine whether successful regional practices can be replicated across other crops and locations.
